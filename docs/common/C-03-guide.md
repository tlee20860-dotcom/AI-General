## 一、開場 SOP

**AI 讀 C-00-startup 後**：

| 步驟 | 動作 |
|---|---|
| 1 | 回報「已讀取 startup」 |
| 2 | 生成對話編號（見 C-00 §三） |
| 3 | 自報編號 |
| 4 | 依議題表驅動制提示下一議題（見 D-050） |
| 5 | 列 4 選項 |
| 6 | 待使用者選擇 |

**議題表驅動提示範例**：

> 🆔 A20261013-005 #001
>
> 已讀取 startup 檔。
> 本對話編號：A20261013-005
> 建議下一議題：議題 7（新專案模板）
>
> 請告知本次情境：
> 1. 新專案 2. 舊專案 3. 純討論 4. 其他

### 1.1 使用者選「新專案」

| 步驟 | 動作 |
|---|---|
| 1 | **AI 先問領域**（見 C-00 §十一） |
| 2 | 使用者回答領域 |
| 3a | 已有領域 → 直接開新專案 |
| 3b | 新領域 → AI 主動建議建 `{X}-*` 6 檔 |

### 1.2 使用者選「舊專案」

| 步驟 | 動作 |
|---|---|
| 1 | AI 說「請提供 INDEX URL 或 2 條 STARTUP URL」 |
| 2 | 使用者貼 URL |
| 3 | AI 讀取（**上傳檔或貼 URL 皆可**） |
| 4 | 依進度繼續 |

### 1.3 使用者選「純討論」

AI 說「請描述問題」。

## 五、對話流程（典型）

### 5.1 已記住 URL 的日常對話

| 步驟 | 誰 | 動作 |
|---|---|---|
| 1 | 你 | 貼 2 條 STARTUP URL |
| 2 | 你 | 說「請讀取上述 URL」 |
| 3 | AI | 讀取 + 生成編號 + 提示議題 + 列 4 選項 |
| 4 | 你 | 選情境 |
| 5 | AI | 依情境處理 |
| 6 | 你 | 說明需求 |
| 7 | AI | 跑 5 問 → 提供方案 |
| 8 | 你 | 確認 |
| 9 | AI | 交付 |
| 10 | 你 | 測試回報 |
| 11 | AI | 修正或完成 |
| 12 | AI | 對話結束前綜合記憶 + 顯示 Token |

### 5.2 忘記 URL 時

| 步驟 | 誰 | 動作 |
|---|---|---|
| 1 | 你 | 貼 INDEX.md URL |
| 2 | AI | 讀取 + 列出所有專案 |
| 3 | 你 | 說要哪個專案 |
| 4 | AI | 給 2 條 STARTUP URL |
| 5 | 你 | 貼 2 條 URL |
| 6 | 後續同 5.1 步驟 3 起 |

### 5.3 首次或新對話（備份方案）

若 URL 機制尚未建立，仍可用上傳檔案：

| 步驟 | 動作 |
|---|---|
| 1 | 你上傳啟動包（見 C-00 §十） |
| 2 | 後續同 5.1 步驟 2 起 |

## 七之三、議題表驅動制（D-050~D-057）

**觸發**：每次對話開場時。

## 七之四、新專案領域詢問（D-137）

**觸發**：使用者選「新專案」時。

| 步驟 | AI 動作 |
|---|---|
| 1 | 問「這個專案屬於哪個領域？」 |

| 3a | 已有領域 → 直接開新專案 |
| 3b | 新領域 → 主動建議建 `{X}-*` 6 檔 |
| 4 | 使用者確認 → 產出 6 檔草稿 |

## 七之五、貼 URL 機制（D-136）

**觸發**：對話開場或使用者選「舊專案」時。

| 情境 | AI 動作 |
|---|---|
| 使用者貼 2 條 STARTUP URL | 讀取 → 依進度繼續 |
| 使用者貼 INDEX.md URL | 讀取 → 列出所有專案 → 問要哪個 → 給 2 條 URL |

**URL 自動產生**：由 GitHub Actions 產出（見 P-15 重組計畫）。

## 八、新專案骨架判斷

| 專案特徵 | 建議檔數 |
|---|---|
| 純靜態 / 單頁 | 2 檔 |
| 有狀態 / 多頁 | 4 檔 |
| 有架構 / 多模組 | 6 檔 |
| 複雜 / 多人協作 | 全部 |

**AI 主動說明 → 使用者確認 → 才建檔**。

## 九、常見錯誤（禁止）

| 錯誤 | 正確 |
|---|---|
| 未經確認直接改檔 | 先方案 |
| 直接估算 N 檔 | 先掃描 |
| 從現況推論範圍 | 從理想推論 |
| 忽略使用者偏好 | 讀 C-01 |
| 忘記記錄教訓 | 對話結束綜合 |
| 忘記顯示 Token 狀態 | 見 C-02 §零點五 |
| 問題與選項分開 | 見 C-02 §二之一 |
| 議題編號與選項混淆 | 見 C-02 §9.4 |
| 通用內容寫入 P-* | 見 C-02 §零點八 |
| 未讀當前版本就重寫 | 見 C-02 §四之一 |
| 用「Repo A」代稱 | 見 C-02 §十三之一 |
