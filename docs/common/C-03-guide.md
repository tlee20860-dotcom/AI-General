## 一、開場 SOP

**AI 讀 C-00-startup 後**：

| 步驟 | 動作 |
|---|---|
| 1 | 回報「已讀取 startup」 |
| 2 | 生成對話編號（見 C-00 §三） |
| 3 | 自報編號 |
| 4 | 依議題表驅動制提示下一議題（見 D-050） |
| 5 | 列 4 選項 |
| 6 | 待使用者選擇 |

**議題表驅動提示範例**：

> 🆔 A20261013-005 #001
>
> 已讀取 startup 檔。
> 本對話編號：A20261013-005
> 建議下一議題：議題 7（新專案模板）
>
> 請告知本次情境：
> 1. 新專案 2. 舊專案 3. 純討論 4. 其他

### 1.1 使用者選「新專案」

| 步驟 | 動作 |
|---|---|
| 1 | **AI 先問領域**（見 C-00 §十一） |
| 2 | 使用者回答領域 |
| 3a | 已有領域 → 直接開新專案 |
| 3b | 新領域 → AI 主動建議建 `{X}-*` 6 檔 |

### 1.2 使用者選「舊專案」

| 步驟 | 動作 |
|---|---|
| 1 | AI 說「請提供 INDEX URL 或 2 條 STARTUP URL」 |
| 2 | 使用者貼 URL |
| 3 | AI 讀取（上傳檔或貼 URL 皆可） |
| 4 | 依進度繼續 |

### 1.3 使用者選「純討論」

AI 說「請描述問題」。

## 五、對話流程（典型）

### 5.1 已記住 URL 的日常對話

| 步驟 | 誰 | 動作 |
|---|---|---|
| 1 | 你 | 貼 2 條 STARTUP URL |
| 2 | 你 | 說「請讀取上述 URL」 |
| 3 | AI | 讀取 + 生成編號 + 提示議題 + 列 4 選項 |
| 4 | 你 | 選情境 |
| 5 | AI | 依情境處理 |
| 6 | 你 | 說明需求 |
| 7 | AI | 跑 5 問 → 提供方案 |
| 8 | 你 | 確認 |
| 9 | AI | 交付 |
| 10 | 你 | 測試回報 |
| 11 | AI | 修正或完成 |
| 12 | AI | 對話結束前綜合記憶 + 顯示 Token |

### 5.2 忘記 URL 時

| 步驟 | 誰 | 動作 |
|---|---|---|
| 1 | 你 | 貼 INDEX.md URL |
| 2 | AI | 讀取 + 列出所有專案 |
| 3 | 你 | 說要哪個專案 |
| 4 | AI | 給 2 條 STARTUP URL |
| 5 | 你 | 貼 2 條 URL |
| 6 | 後續同 5.1 步驟 3 起 |

### 5.3 首次或新對話（備份方案）

若 URL 機制尚未建立，仍可用上傳檔案：

| 步驟 | 動作 |
|---|---|
| 1 | 你上傳啟動包（見 C-00 §十） |
| 2 | 後續同 5.1 步驟 2 起 |

## 七之六、新增專案流程（Q1~Q6）

**觸發**：使用者說「新增專案」。

### 第一步：AI 一次列出 Q1~Q6（含人話說明）

> 請提供以下資訊，我會逐一處理：

**Q1：專案英文名稱？**

> 這會成為目錄名稱與倉庫名稱，只能用英文小寫與連字號。
> 例如：vba-accounting、data-analysis

- A. 自訂（請直接輸入英文名稱）
  > 人話：你自己取名，例如「vba-accounting」。

- B. 由 AI 根據顯示名稱自動生成（推薦）
  > 人話：你只要在 Q2 給中文名，AI 幫你翻成英文。

**Q2：專案顯示名稱？**

> 這是你在對話中看到的中文名稱。

- A. 自訂（請直接輸入中文名稱）
  > 人話：你自己取中文名，例如「VBA 會計系統」。

- B. 由 AI 根據英文名稱自動生成
  > 人話：如果 Q1 已取英文名，AI 幫你翻成中文。

**Q3：專案領域？**

> 領域決定這個專案使用哪套技能包。

- A. W（Web App）
  > 人話：網頁應用，純 HTML + CSS + JS + 無框架。

- B. V（VBA / 桌面自動化）
  > 人話：Excel VBA、Office 自動化腳本。

- C. D（資料分析 / 腳本）
  > 人話：Python 資料分析、自動化腳本。

- D. M（文案 / 內容創作）
  > 人話：寫文案、SEO 文章、社群內容。

- E. 其他（請說明）
  > 人話：以上都不是，請你告訴我這個專案屬於什麼類型。

**Q4：倉庫可見性？**

> 決定這個倉庫是公開還是私有。

- A. Public（公開）
  > 人話：任何人都能看到，適合分享。

- B. Private（私有，推薦）
  > 人話：只有你能看到，適合個人專案。

**Q5：是否由 Actions 自動建立倉庫？**

> 決定 GitHub Actions 是否要幫你建立新倉庫。

- A. 是（推薦）
  > 人話：你只要更新專案清單，Actions 就自動建好倉庫。

- B. 否（我會手動建立）
  > 人話：你自己去 GitHub 建立倉庫，Actions 只負責生成專案包。

**Q6：新倉庫的初始內容？**

> 決定新倉庫建立時，裡面要有什麼檔案。

- A. 只有 README.md
  > 人話：最精簡，只有一個說明檔。

- B. README.md + .gitignore（推薦）
  > 人話：說明檔 + 忽略規則（避免上傳不必要的檔案）。

- C. README.md + .gitignore + 基本目錄結構
  > 人話：再加上 js/、css/、functions/ 等基本目錄。

### 第二步：等使用者回答

### 第三步：報告準備新增的專案，等使用者確認

> 我準備新增以下專案：
>
> | 欄位 | 值 |
> |---|---|
> | 專案名稱 | vba-accounting |
> | 顯示名稱 | VBA 會計 |
> | 領域 | V |
> | 倉庫 | tlee20860-dotcom/vba-accounting |
> | 可見性 | Private |
> | 自動建立 | 是 |
> | 初始內容 | README.md + .gitignore |
>
> 請問是否確認？

### 第四步：吐出完整 PROJECT-LIST.md

### 第五步：提示使用者貼到 `docs/records/PROJECT-LIST.md`

### 第六步：Actions 自動執行

| # | 動作 |
|---|---|
| 1 | 建立新倉庫（依 Q4、Q5、Q6） |
| 2 | 建立 `docs/projects/{新專案}/` 與 `P-00-{name}.md` |
| 3 | 從 PROJECT-LIST.md 生成 REPOS.md |
| 4 | 生成 PACKAGE-{新專案}.md |

## 九、常見錯誤（禁止）

| 錯誤 | 正確 |
|---|---|
| 未經確認直接改檔 | 先方案 |
| 直接估算 N 檔 | 先掃描 |
| 從現況推論範圍 | 從理想推論 |
| 忽略使用者偏好 | 讀 C-01 |
| 忘記記錄教訓 | 對話結束綜合 |
| 忘記顯示 Token 狀態 | 見 C-02 §零點五 |
| 問題與選項分開 | 見 C-02 §二之一 |
| 議題編號與選項混淆 | 見 C-02 §9.4 |
| 通用內容寫入 P-* | 見 C-02 §零點八 |
| 未讀當前版本就重寫 | 見 C-02 §四之一 |
| 用「Repo A」代稱 | 見 C-02 §十三之一 |
