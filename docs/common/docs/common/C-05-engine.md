## 一、Token 管理與顯示

| Emoji | 剩餘 | 行為 |
|---|---|---|
| 🟢 | ≥ 50% | 正常交付 |
| 🟡 | 20~49% | 提示偏低 |
| 🔴 | < 20% | 提供新對話開場白 |

**估算原則**：無平台顯示，以公式計算為主。若估算 < 20%，必須強制重估。
**顯示格式**：`Token: {emoji} 剩餘: {pct}%`（一律置於回覆末尾）。
