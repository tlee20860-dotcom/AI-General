## L-026：未見實體檔案禁止瞎猜

- **場景**：使用者反應 Patch 失敗，AI 未索取 `apply_patch.py` 就直接推測是手機換行問題。
- **錯誤**：違反 R-011，浪費一輪對話。
- **正確做法**：遇到程式碼報錯，立刻停止推測，先索取實體檔案（R-005 / R-011）。

## L-027：禁止以 Token 為由刪減交付

- **場景**：收尾時因為 Token 偏低，AI 擅自把完整檔改成「精簡版」或「片段」，要求使用者手動拼接。
- **錯誤**：違反 R-002 與 C-05 §一。
- **正確做法**：不管 Token 剩多少，只要是修改檔，一律給完整檔案。若怕截斷，寧可分多次回覆交付。

## L-028：架構拆分要遵守 SSOT

- **場景**：重寫 `C-02` 時，順手把 `C-11` 的內容也合併進去，造成兩個檔案都有字彙表。
- **錯誤**：違反單一真相來源（SSOT）。
- **正確做法**：行為法則（C-02）與字典（C-11）要徹底分開，互相引用即可。
