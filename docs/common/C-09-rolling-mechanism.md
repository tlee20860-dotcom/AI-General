## 一、目的

## 二、機制規則（D-001 / D-002 / D-003 / D-005 / D-006）

| 項目 | 規則 |
|---|---|
| 觸發 | 每次議題結論後 |
| 產出 | 「累積結論」= 上一輪完整內容 + 本輪新增 |
| 已結論內容 | 不修改，只追加 |
| 格式 | 與 C-04 交付格式完全一致 |
| 省略 | 禁止（必須完整） |
| 觸發詞 | 使用者說「議題結案」 |

| 層 | 檔案 | 職責 |
