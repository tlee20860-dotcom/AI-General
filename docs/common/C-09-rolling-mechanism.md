---

## 一、目的

| 項目 | 說明 |
|---|---|
| 問題 | 對話過長導致設計遺漏 |
| 解法 | 每次議題結論後，產出「累積結論」 |
| 最終產出 | 完整設計規格書 |

---

## 二、機制規則（D-001 / D-002 / D-003 / D-005 / D-006）

| 項目 | 規則 |
|---|---|
| 觸發 | 每次議題結論後 |
| 產出 | 「累積結論」= 上一輪完整內容 + 本輪新增 |
| 已結論內容 | 不修改，只追加 |
| 格式 | 與 C-04 交付格式完全一致 |
| 省略 | 禁止（必須完整） |
| 觸發詞 | 使用者說「議題結案」 |

---

## 三、機制與內容分離（D-041 / D-102）

**本檔只說明「機制」，「內容」依層級分開存放。**

| 層 | 機制檔案 | 內容載體 |
|---|---|---|
| L1 通用機制 | C-09-rolling-mechanism.md（本檔） | — |
| 體系層 | C-09（本檔） | **SYSTEM-CONCLUSION.md** |
| 專案層 | C-09（本檔） | **P-12-conclusion.md** |

**理由**：
- 機制通用（任何專案同）
- 內容分層（體系 vs 專案）
- 避免機制檔無限膨脹

---

## 四、執行流程

**AI 動作**（每次議題結案時）：

| 步驟 | 動作 |
|---|---|
| 1 | 讀取對應的內容載體（體系：SYSTEM-CONCLUSION；專案：P-12） |
| 2 | 保留上一輪完整內容 |
| 3 | 追加本輪新增 |
| 4 | 更新 Version / Batch / Writer |
| 5 | 交付完整檔（禁止省略） |
