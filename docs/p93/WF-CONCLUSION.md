## 二、設計結論

### 2.1 全新技術棧（D-93-001 定案）
1. **前端**：Vue 3 (Composition API) + Vite + Element Plus。
2. **後端**：Supabase (PostgreSQL)。
3. **狀態與路由**：Vue Router。
4. **部署**：Cloudflare Pages。

### 2.2 網路代理機制（D-93-002 定案）
1. **背景**：特定電信商會封鎖 `*.supabase.co` 的 DNS。
2. **解法**：建立 `functions/api/supabase/[[path]].js`，透過 Cloudflare Workers 進行反向代理。
3. **防呆**：過濾所有 Cloudflare 內部標頭（如 `cf-connecting-ip`），並使用 `arrayBuffer` 讀取 Body，徹底解決 `HTTP 530` 崩潰。

### 2.3 虛擬帳號登入（D-93-003 定案）
1. **背景**：家庭成員不習慣輸入完整 Email。
2. **解法**：前端 `LoginView.vue` 攔截輸入，自動補齊 `@fs-app.com` 後綴。使用者只需輸入 `admin` 或 `老婆` 即可登入。

### 2.4 高自由度輸入與連動（D-93-004 定案）
1. **自訂分類**：在收支流水輸入新分類時，系統自動寫入資料庫，下次即可直接選用。
2. **固定支出模板**：設定頁可建立模板，收支頁可一鍵匯入當月固定開銷。
3. **保險成本推算**：基金成本不需手動輸入，系統根據「關聯保單月均 × 已繳月數 × 分配比例」自動即時推算。
4. **真實盈虧**：基金盈虧公式為 `(當前現值 + 已提款) - 投入成本`，精準反映真實獲利。
