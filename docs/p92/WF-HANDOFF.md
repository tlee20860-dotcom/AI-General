## 一、專案狀態摘要
本專案已完成重大架構重構與使用者體驗優化。
- **彈窗三層架構**：`modal.js` 已重構為標題固定、內容滾動、底部按鈕固定，徹底解決手機端按鈕錯位問題。
- **製程模板與類別綁定**：新增「製程模板」管理，可設定對應的工單類別（如 GF、LS），匯入時自動套用對應的 SOP。
- **工單專屬製程微調**：表格與卡片中的狀態欄位改為「上一個工序 / 當前工序 / 下一個工序」的按鈕，並附帶 ⚙️ 按鈕可開啟雙清單編輯器，快速套用模板並微調。
- **行內編輯**：支援在表格與卡片中直接修改文字與日期（如交貨日期），背景自動存檔並顯示提示。
- **全域設定即時監聽**：`main.js` 加入 `listenDocument('settings')`，在設定頁修改工序或模板後，前台頁面會立刻刷新，不需再手動切換頁面。
- **全域搜尋**：移除表格行內篩選列，改為右上角單一搜尋框，輸入關鍵字即可跨欄位過濾。
- **設定頁重構**：`settings.js` 已拆分為 `settings.js`、`settings-basic.js`、`settings-schema.js`，維持良好維護性。
