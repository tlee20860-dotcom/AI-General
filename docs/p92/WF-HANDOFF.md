## 一、專案狀態摘要
本專案經歷了重大重構與功能擴充，現已具備完善的權限控制、自動化與推播能力。
- **角色權限矩陣**：實作 `admin`（全權）、`worker`（僅區域，可推進度）、`sales`（僅銷售員，唯讀）、`viewer`（全站唯讀）四種角色。路由、選單與渲染層皆有防護。
- **生產區域管理**：新增區域綁定與類別過濾，並支援「區域狀態」（如正常、壞機）切換。
- **進度控制台重構**：頂部改為「類別分頁」，下方按「工序」分區塊顯示。
- **銷售員視圖重構**：同樣按「工序」分區塊，並自動顯示工單目前所在的「生產區域」。
- **SortableJS 拖曳**：手機與電腦端皆可流暢拖曳排序（取代上下箭頭按鈕）。
- **本機 Excel 自動同步**：使用 File System Access API，授權資料夾後可自動監測存檔並匯入。
- **原生推播通知**：工單狀態更新時，會比對角色權限發送瀏覽器原生通知（需保持分頁在背景）。
