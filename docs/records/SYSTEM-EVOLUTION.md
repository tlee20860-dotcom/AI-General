# SYSTEM-EVOLUTION（體系進化史）

用途：記錄體系從無到有、逐步成形的架構級變化。只記「形態與關鍵轉折」，不重複決策明細（見 `SYSTEM-CONCLUSION.md`）與任務進度（見 `PROGRESS.md`）。
模式：APPEND_ONLY（只追加，不改舊段）。
上限：無（追加式，長期累積）。

---

## 零、閱讀說明

| 項目 | 說明 |
|---|---|
| 本檔記什麼 | 體系形態的架構級變化、載體搬遷、制度誕生 |
| 本檔不記什麼 | 每條決策明細、每次任務進度、個別 bug 修復 |

| 史料邊界 | B29 之前**不存在體系概念**，本檔不將其視為體系前身 |
