### 2.49 前端污染修復與檢查機制對齊（SV10 定案）
1. **解決致命污染 Bug**：修復前端 `index.html` 誤將內文包含 `[APPEND]` 字串的完整檔當作增量附加，導致 `R-00` 與 `R-03` 等源檔重複膨脹。現改為嚴格判定首行標記，並精準切除舊 EOF。
2. **檢查機制全面對齊**：禁用詞統一由 `forbidden_words.txt` 管理，並移除了白名單放行邏輯。前端新增「累積型檔案覆蓋攔截」與「JSON `_EOF` 識別」，確保與 CI 腳本（`validate_delivery.py`）行為一致。
3. **建立 R-027 同步義務**：新增「規則—檢查同步義務」鐵律，明定修改 R-00 可檢查條文時，必須同步修改前端、CI 與配置檔，並附上對照表。
4. **R-05 DSL 重構**：引進 `scope: INTERNAL_COT_ONLY` 防護，全面補齊 `ELSE -> PASS_THROUGH` 避免邏輯死鎖，並將複雜條件改為多行折疊。
5. **雙卡片高亮與救援**：前端被擋下時，提供「倉庫舊內容」與「本次貼上內容」雙卡片對比，並將禁用詞以紅字高亮，標記〔既有〕或〔新增〕，方便肉眼核對。
