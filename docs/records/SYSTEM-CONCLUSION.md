## 二、設計結論

### 2.1 連結啟動與快照鎖定（SV15 定案）
1. **雙軌啟動**：允許實體檔與純文字連結（Raw Link）雙軌並行。
2. **實體優先**：若同時存在實體檔與連結，優先採用實體檔。
3. **快照鎖定**：連結讀取後即視為靜態快照，建立會話鎖後嚴禁重新抓取同一 URL（`I-13`）。
4. **控制台優化**：`index.html` 新增 `[SYSTEM BOOTSTRAP]` 啟動咒語，並實作 `packages.json` 動態清單，減少硬編碼。
